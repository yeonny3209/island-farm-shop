# 🏝️ 작은 섬 농장 가게

작은 섬의 버려진 밭과 가게를 물려받았는데, 빚 **5,000G**도 함께 물려받았습니다.
**48일** 안에 작물을 키워 내 가게에서 팔고 빚을 갚는 농장 + 가게 경영 시뮬레이션입니다.

**▶ 웹에서 플레이: https://yeonny3209.github.io/island-farm-shop/**
**📲 안드로이드 앱(APK): https://github.com/yeonny3209/island-farm-shop/releases/latest/download/island-farm-shop.apk**

## 휴대폰 · 태블릿에 설치하기

- **안드로이드**: 위 APK 링크를 휴대폰이나 태블릿에서 열어 내려받고, 파일을 열어 설치합니다. 처음 한 번은 "출처를 알 수 없는 앱" 설치를 허용해야 할 수 있습니다. 설치하면 앱처럼 실행되고 인터넷 없이도 할 수 있습니다. 새 버전 APK를 설치하면 저장은 그대로 남습니다.
- **아이폰 · 아이패드**: Safari로 웹 주소를 열고 공유 버튼 → "홈 화면에 추가". 앱처럼 전체 화면으로 열리고, 한 번 연 뒤에는 오프라인에서도 됩니다.
- **안드로이드 크롬**: 게임 화면의 📲 버튼 → "홈 화면에 설치"로도 설치할 수 있습니다.

웹에서 하던 게임과 앱의 저장은 따로 보관됩니다. 💾 저장 → "저장 코드 만들기"로 만든 코드를 다른 기기에 붙여 넣으면 이어서 할 수 있습니다.

## 저장과 건너뛰기

- **자동 저장**: 하루가 끝날 때, 앱을 내리거나 닫을 때 저절로 저장됩니다.
- **저장 슬롯 3개**: 💾 버튼에서 언제든 저장하고, 불러오고, 지울 수 있습니다.
- **저장 코드**: 휴대폰 ↔ 태블릿, 웹 ↔ 앱 사이로 게임을 옮길 때 씁니다.
- **⏭ 건너뛰기**: 1일 · 3일 · 7일을 한 번에 넘깁니다. 건너뛰는 날에도 진열대 그대로 가게를 열고(끌 수 있음) 다 자란 작물을 거둘 수 있습니다. 물은 비와 스프링클러가 준 칸만 받습니다. 빚이 남아 있으면 마감일 밤에서 멈춥니다.

## 하루의 흐름

| 순서 | 할 일 |
| --- | --- |
| 🌅 아침 | 날씨, 오늘의 인기 작물, 내일 예보 확인 |
| 🌱 밭 작업 | 도구를 고르고 칸을 누름 (누른 채 끌면 여러 칸). 심기 2, 물 주기 3, 수확 1 체력 |
| 🧺 가게 준비 | 창고의 작물을 진열대로 끌어다 놓고 가격 슬라이더로 값을 정함 |
| 🏪 영업 | 손님이 오가며 사거나 그냥 가는 장면이 재생됨 |
| 🌙 밤 | 영수증으로 정산, 씨앗·업그레이드 구매, 빚 갚기, 잠자기(자동 저장) |

단축키: `1` 심기 · `2` 물 주기 · `3` 수확 · `4` 스프링클러 · `5` 뽑기

## 시스템

- **계절**: 봄·여름·가을·겨울 각 12일. 계절이 바뀌면 지난 계절 작물은 시듭니다. 겨울엔 야외 밭이 얼어서 온실이 없으면 모아 둔 작물로 장사해야 합니다.
- **작물 40종**: 계절마다 10종(빠른 작물 4 · 느린 작물 3 · 재수확 작물 3). 수치는 게임 안 도움말(`?`)과 [`js/data.js`](js/data.js)에 있습니다.
- **가격**: 기준가로 팔면 손님 80%가 사고, 1.5배면 30%만 삽니다. 인기 작물은 40% 비싸도 기준가처럼 팔리고, 싸게 팔면 한 번에 여러 개 사 갑니다.
- **질림**: 같은 물건을 3개까지는 괜찮지만 **4개째 팔 때부터** 손님이 질려서 덜 삽니다(최근 판매 개수가 늘수록 구매 확률이 떨어지고, 하루마다 20%씩 잊음). 상추만 심는 식의 한 가지 작물 전략은 통하지 않고, 여러 작물과 가공품을 섞어야 합니다.
- **날씨**: 맑음 / 비(밭에 물이 저절로, 손님 감소) / 폭풍(휴업, 전날 예보). 겨울엔 눈과 눈보라.
- **업그레이드**: 밭 확장(4×4 → 8×8), 물뿌리개 개량, 스프링클러, 진열대 추가, 가공 공방, 온실, 가게 간판.
- **가공품**: 가공 공방(장독대)을 지으면 항아리가 생깁니다(2 → 4 → 6개). 항아리 하나에 작물을 **1~3가지 섞어 모두 합쳐 5개**까지 넣으면 2일 뒤 아침에 가공품이 창고로 들어옵니다. 한 가지만 넣으면 딸기잼·상추 피클처럼 되고(예: 딸기 55G → 딸기잼 95G), 과일끼리 섞으면 🍯 모둠 잼, 채소끼리 섞으면 🥫 모둠 피클, 과일과 채소를 섞으면 🍲 가든 스튜가 됩니다. 섞는 종류가 하나 늘 때마다 값이 8%씩 더 올라서 따로 가공할 때보다 20~40% 비싸게 팔립니다. 가공품은 계절을 타지 않아 손님이 꾸준히 찾고 겨울엔 더 많이 찾습니다. 항아리에 넣는 데는 체력이 들지 않고 낮과 밤 모두 가능합니다.
- **엔딩**: 빚을 다 갚으면 엔딩을 보고 계속 플레이할 수 있습니다. 48일째 밤까지 못 갚으면 가게를 잃습니다.

### 기획서에서 더한 것

밸런스 시뮬레이션에서 기획서 8장의 걱정("항상 기준가의 1.2배 같은 정답")이 실제로 나타나서 두 가지를 더했습니다.

- **손님이 찾는 작물**: 손님마다 사고 싶은 작물이 있고 제철 작물과 인기 작물을 많이 찾습니다. 찾는 게 진열대에 없으면 둘러보다 그냥 가기도 합니다. 한 작물만 심으면 손해가 나고, 진열대 칸 수가 의미를 갖습니다.
- **가게 평판**: 적당한 값에 산 손님은 평판을 올리고, 비싸서 그냥 간 손님은 떨어뜨립니다. 평판은 다음 날 손님 수에 곱해집니다. 비싸게 받으면 오늘은 이득이지만 내일 손님이 줄어듭니다.

## 밸런스 시뮬레이션

기획서 7장 2단계("평범하게 플레이하면 며칠째에 빚을 갚는지")를 위해 여러 성향의 자동 플레이어가 실제 게임 규칙으로 48일을 플레이하는 스크립트가 있습니다.

```bash
node tools/balance.js 300            # 전략별 성공률, 빚 청산일, 평균 매출
node tools/balance.js 100 --diag 2   # 2번 전략의 하루 평균 지표 (진열·판매·손님·순자산)
node tools/balance.js 1 --trace 3    # 3번 전략 한 판을 하루씩 출력
```

현재 수치로 300판을 돌린 결과(요약):

| 전략 | 성공률 | 빚 청산일(중앙값) |
| --- | --- | --- |
| 상추만 · 기준가 · 업그레이드 없음 | 약 65% | 33일 |
| 섞어 심기 · 기준가 · 기본 업그레이드 | 약 50% | 31일 |
| 섞어 심기 · 가격 조절 · 기본 업그레이드 | 100% | 30일 |
| 위와 같음 + 가공 공방(항아리 2개) | 100% | 29일 (매출 +500G) |
| 위와 같음 + 가공 공방(항아리 4개) | 100% | 30일 (매출 +1,500G) |
| 가치 계산 · 가격 조절 · 많은 업그레이드 | 약 99% | 30일 |
| 가격 항상 80% / 90% | 0~2% | - |
| 가격 항상 120% / 150% | 약 98% / 67% | 31일 / 35일 |

수치를 바꿀 때는 `js/data.js`만 고치고 위 스크립트로 결과를 확인하면 됩니다.


그다음 http://localhost:5173 을 엽니다. (`index.html`을 바로 열어도 동작합니다.)

## 안드로이드 APK 빌드

`main`에 게임 파일이 바뀌어 올라오면 GitHub Actions(`.github/workflows/android.yml`)가 Capacitor로 안드로이드 프로젝트를 만들고, 서명된 APK를 빌드해 [Releases](https://github.com/yeonny3209/island-farm-shop/releases)에 올립니다. Actions 탭에서 "안드로이드 APK"를 직접 실행할 수도 있습니다.

- 서명 키는 저장소 Secrets(`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`)에 있습니다. 같은 키로 서명해야 설치된 앱 위에 업데이트가 됩니다.
- 로컬에서 안드로이드 프로젝트를 만들려면 `npm install` 후 `npm run android:add` (빌드에는 Android Studio/SDK가 필요합니다).
- 스크립트·스타일을 고치면 `index.html`의 `?v=` 값과 `sw.js`의 `VERSION`을 함께 올려 주세요. 그래야 이미 연 브라우저에도 새 버전이 바로 들어갑니다.

## 파일 구성

```
index.html        화면 뼈대
css/style.css     스타일 (시간대별 바다 배경, 섬, 가게, 영수증)
js/data.js        수치표: 작물, 가공품, 날씨, 업그레이드, 밸런스 상수
js/engine.js      게임 규칙 (화면과 분리된 순수 로직, Node에서도 동작)
js/ui.js          그리기와 입력, 영업 장면 재생, 저장·건너뛰기
manifest.webmanifest, sw.js   홈 화면 설치(PWA)와 오프라인 지원
icons/            앱 아이콘 (tools/make-icons.js 로 생성)
capacitor.config.json         안드로이드 앱 설정
.github/workflows/android.yml APK 자동 빌드
tools/balance.js  밸런스 시뮬레이션
tools/make-icons.js 아이콘 그리기 (의존성 없음)
tools/build-web.js  앱에 넣을 웹 파일을 www/ 로 모으기
tools/serve.js    로컬 정적 서버 (의존성 없음)
```
