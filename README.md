# 🏝️ 작은 섬 농장 가게

작은 섬의 버려진 밭과 가게를 물려받았는데, 빚 **5,000G**도 함께 물려받았습니다.
**40일 안에** 작물을 키워 내 가게에서 팔고 빚을 갚는 농장 + 가게 경영 시뮬레이션입니다.

**▶ 플레이: https://yeonny3209.github.io/island-farm-shop/**

설치할 것 없이 브라우저에서 바로 돌아갑니다. 진행은 하루가 끝날 때마다 브라우저(localStorage)에 자동 저장됩니다.

## 하루의 흐름

| 순서 | 할 일 |
| --- | --- |
| 🌅 아침 | 날씨, 오늘의 인기 작물, 내일 예보 확인 |
| 🌱 밭 작업 | 도구를 고르고 칸을 누름 (누른 채 끌면 여러 칸). 심기 2, 물 주기 3, 수확 1 체력 |
| 🧺 가게 준비 | 창고의 작물을 진열대로 끌어다 놓고 가격 슬라이더로 값을 정함 |
| 🏪 영업 | 손님이 오가며 사거나 그냥 가는 장면이 재생됨 |
| 🌙 밤 | 영수증으로 정산, 씨앗·업그레이드 구매, 빚 갚기, 잠자기(자동 저장) |

단축키: `1` 심기 · `2` 물 주기 · `3` 수확 · `4` 스프링클러 · `5` 뽑기

## 시스템

- **계절**: 봄·여름·가을·겨울 각 10일. 계절이 바뀌면 지난 계절 작물은 시듭니다. 겨울엔 야외 밭이 얼어서 온실이 없으면 모아 둔 작물로 장사해야 합니다.
- **작물 12종**: 계절마다 빠른 작물 / 느린 작물 / 재수확 작물 한 가지씩. 수치는 게임 안 도움말(`?`)과 [`js/data.js`](js/data.js)에 있습니다.
- **가격**: 기준가로 팔면 손님 80%가 사고, 1.5배면 30%만 삽니다. 인기 작물은 40% 비싸도 기준가처럼 팔리고, 싸게 팔면 한 번에 여러 개 사 갑니다.
- **날씨**: 맑음 / 비(밭에 물이 저절로, 손님 감소) / 폭풍(휴업, 전날 예보). 겨울엔 눈과 눈보라.
- **업그레이드**: 밭 확장(4×4 → 8×8), 물뿌리개 개량, 스프링클러, 진열대 추가, 온실, 가게 간판.
- **엔딩**: 빚을 다 갚으면 엔딩을 보고 계속 플레이할 수 있습니다. 40일째 밤까지 못 갚으면 가게를 잃습니다.

### 기획서에서 더한 것

밸런스 시뮬레이션에서 기획서 8장의 걱정("항상 기준가의 1.2배 같은 정답")이 실제로 나타나서 두 가지를 더했습니다.

- **손님이 찾는 작물**: 손님마다 사고 싶은 작물이 있고 제철 작물과 인기 작물을 많이 찾습니다. 찾는 게 진열대에 없으면 둘러보다 그냥 가기도 합니다. 한 작물만 심으면 손해가 나고, 진열대 칸 수가 의미를 갖습니다.
- **가게 평판**: 적당한 값에 산 손님은 평판을 올리고, 비싸서 그냥 간 손님은 떨어뜨립니다. 평판은 다음 날 손님 수에 곱해집니다. 비싸게 받으면 오늘은 이득이지만 내일 손님이 줄어듭니다.

## 밸런스 시뮬레이션

기획서 7장 2단계("평범하게 플레이하면 며칠째에 빚을 갚는지")를 위해 여러 성향의 자동 플레이어가 실제 게임 규칙으로 40일을 플레이하는 스크립트가 있습니다.

```bash
node tools/balance.js 300            # 전략별 성공률, 빚 청산일, 평균 매출
node tools/balance.js 100 --diag 2   # 2번 전략의 하루 평균 지표 (진열·판매·손님·순자산)
node tools/balance.js 1 --trace 3    # 3번 전략 한 판을 하루씩 출력
```

현재 수치로 300판을 돌린 결과(요약):

| 전략 | 성공률 | 빚 청산일(중앙값) |
| --- | --- | --- |
| 상추만 · 기준가 · 업그레이드 없음 | 약 65% | 33일 |
| 섞어 심기 · 기준가 · 기본 업그레이드 | 약 50% | 31일 |
| 섞어 심기 · 가격 조절 · 기본 업그레이드 | 100% | 30일 |
| 가치 계산 · 가격 조절 · 많은 업그레이드 | 약 99% | 30일 |
| 가격 항상 80% / 90% | 0~2% | - |
| 가격 항상 120% / 150% | 약 98% / 67% | 31일 / 35일 |

수치를 바꿀 때는 `js/data.js`만 고치고 위 스크립트로 결과를 확인하면 됩니다.

## 로컬에서 실행

```bash
node tools/serve.js
```

그다음 http://localhost:5173 을 엽니다. (`index.html`을 바로 열어도 동작합니다.)

## 파일 구성

```
index.html        화면 뼈대
css/style.css     스타일 (시간대별 바다 배경, 섬, 가게, 영수증)
js/data.js        수치표: 작물, 날씨, 업그레이드, 밸런스 상수
js/engine.js      게임 규칙 (화면과 분리된 순수 로직, Node에서도 동작)
js/ui.js          그리기와 입력, 영업 장면 재생, 저장
tools/balance.js  밸런스 시뮬레이션
tools/serve.js    로컬 정적 서버 (의존성 없음)
```
